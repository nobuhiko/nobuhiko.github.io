かさね日記 プライバシーポリシー

「かさね日記」(以下「本アプリ」)は、写真と記録を端末の中だけに保存することを基本に設計しています。本ポリシーは、本アプリが扱う情報とその取り扱いを説明します。

1. 端末内に保存する情報

  • 写真(縮小版とサムネイル)、ひとこと(メモ)、撮影日時
  • その日の天気と最高・最低気温
  • 撮影地の位置情報(緯度経度を小数第 2 位に丸めた、約 1km の精度)と市区町村名
  • 設定(ホーム地点、リマインド時刻)

これらは端末内のデータベースとファイルにのみ保存され、開発者を含む外部のサーバーには送信・保存されません。

2. 外部に送信する情報

気温と天気を取得するため、Open-Meteo の API に次の情報だけを送信します。

  • 緯度経度(小数第 1 位に丸めた、約 10km の精度)
  • 日付(または期間)

写真、メモ、氏名、メールアドレスなど個人を特定できる情報は送信しません。Open-Meteo の取り扱いは同サービスのポリシーに従います。

ホーム地点を地名で検索する場合、入力した地名を Open-Meteo の地名検索 API に送信します。

3. 利用する端末の機能と権限

  • カメラ: きょうの 1 枚を撮影するため
  • 写真ライブラリ: 写真を選ぶため、および過去の写真を取り込むため。取り込み時は写真の撮影日時と位置情報(EXIF)を読み取り、当時の気温を付けるために使います
  • 位置情報: 現在地の気温を取得するため。取得した位置は丸めてから保存・送信します
  • 通知: 設定した時刻に「きょうの 1 枚」をお知らせするため(端末内で予約するローカル通知です)

市区町村名の取得には、端末の OS が提供する逆ジオコーディング機能(Apple または Google)を使います。

4. 解析・広告

本アプリは、利用状況の解析ツールや広告 SDK を使用していません。

5. お子さまの写真について

本アプリは保護者などの大人が利用することを想定しています。記録した写真は端末の外に出ないため、お子さまの写真が第三者に送信されることはありません。

6. データの削除

アプリ内の設定から記録を削除できるほか、アプリをアンインストールすると保存されたすべての情報が端末から削除されます。

7. 変更

本ポリシーを変更する場合は、このページで公開します。
